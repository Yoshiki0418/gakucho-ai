## 現在の進捗と状況
1. **システム背景:** ユーザーは「学長AI」というペルソナ型の対話システムを構築しています。
2. **課題:** 単一の巨大なLLMにRAG（情報検索）や複雑な推論をさせると、応答遅延（TTFT）が大きくなり、かつプロンプト肥大化によってペルソナが崩壊するという問題がありました。
3. **提案手法:** 「意図分類」「フィラー（相槌）の並行生成」「ドメイン別のマルチエージェント（Handoff）」を組み合わせたアーキテクチャを実装しました。これにより、本回答を生成している間にフィラーをストリーミングして体感遅延を隠蔽し、かつドメインごとの専門エージェントで高品質な回答を実現しています。
4. **実装状況:**
   - マルチエージェント機能とフィラー生成（`app/agent/response_orchestrator.py`）は実装済み。
   - 比較対象となる単一LLMアプローチ（`app/agent/baseline_agent.py`）も実装済み。
   - 評価用データセット（全100問：10カテゴリ×各10件、`backend/benchmark/benchmark_queries.py`）の整備完了。新たに「ドメイン横断の複雑な相談」を追加しました。

## 評価計画について
- **実験1:** フィラー並行生成の有用性（TTFTの隠蔽効果の検証）
- **実験2:** マルチエージェント分割の有用性（単一巨大LLMと比較した際の、ルールの競合回避やペルソナの一貫性の検証）
