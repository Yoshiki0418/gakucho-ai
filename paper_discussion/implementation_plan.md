【実験1】LLM-as-a-Judge によるフィラー品質評価の実行計画
動的フィラー（提案手法）と定型フィラー（比較手法1）の品質差を定量化するため、GPT-4oを用いた自動評価（LLM-as-a-Judge）のスクリプトを作成し実行します。

目的
動的フィラーが、単なる沈黙隠蔽のテンプレートではなく、ユーザーの文脈を理解し、学長ペルソナを維持した「高品質な相槌」であることを証明する。

実装計画
1. 評価スクリプトの作成 (evaluate_filler_quality.py)
ベンチマーク結果のCSVを読み込み、GPT-4oを用いて自動評価を行うスクリプトを作成します。

入力: 先ほど取得した benchmark_20260605_000057.csv
対象: dynamic_filler および static_filler のうち、フィラーが実際に発火した（filler_fired == True）データ（約500件程度）。
LLM呼び出し: 既存の OpenAILLM クラスを利用し、gpt-4o を使用。
出力: 評価結果を付与した新しいCSVファイル（例: filler_evaluation_results.csv）
2. ルーブリック（評価基準）の設計
プロンプト内で以下の3項目について、1〜5の5段階評価を指示し、JSON形式で結果を取得します。

文脈的適切さ (Appropriateness):
ユーザーの発話（Query）の意図や内容を正しく受け止め、自然に会話を繋ぐ相槌になっているか。（例: 検索が必要な質問に対して「調べてみますね」といった意図が含まれているか）
ペルソナ一貫性 (Persona Consistency):
大学の「学長」という立場にふさわしい、威厳がありつつも学生に寄り添う丁寧な言葉遣いになっているか。
自然さ (Naturalness):
機械的なテンプレート感（「少々お待ちください」の単なる繰り返しなど）がなく、人間らしい自然な表現か。
3. 統計分析
評価が完了した後、3つの指標それぞれについて、dynamic_filler と static_filler のスコアの平均値を算出し、Mann-Whitney U検定を用いて統計的有意差（p < 0.05）を証明します。
