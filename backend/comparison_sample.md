## カテゴリ: complex_consult
**ユーザーの質問:** 将来AIエンジニアになりたいのですが何を勉強すべきですか？

### 🤖 Multi-Agent (提案手法)
**回答:** AIエンジニアを目指すうえで、数学とプログラミングを軸に、どの分野のAIに進みたいかも踏まえて整理してみますね。AIエンジニアを目指すなら、まずは「土台 → 実装 → 発信」の順で積むのが近道です。## 1) まず勉強すべき土台（最優先）
Python：文法だけでなく、`NumPy / pandas`でデータ処理まで
数学の基礎：線形代数（行列）、微分、確率・統計（平均・分散・正規分布あたり）
CS基礎：アルゴリズムとデータ構造、計算量の考え方
Git / Linux / Docker（触れる程度でOK）：開発の必須道具

## 2) AIの実装（次にやる）
機械学習：回帰・分類・評価指標・過学習・特徴量の基本
深層学習：ニューラルネット、最適化、CNN、Transformerの概要
LLM実務（今のAIエンジニア寄り） 
API利用、プロンプト設計の基礎 
RAG（社内データ検索＋生成）、ベクトルDB、評価（精度/コスト/速度）

## 3) 仕事につながる形にする（差がつく）
ポートフォリオを3つ（小さくてOK、動くもの）
例：画像分類、需要予測、RAGチャット（PDF検索→回答）
発信：GitHubにコード、学びを短くメモ（継続が強い）
